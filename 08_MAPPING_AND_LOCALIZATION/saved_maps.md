# Saved Maps

## 1. Map Storage

Saved occupancy grid maps are stored in:

```text
~/wheelchair_nav2/maps/
```

Each map consists of a YAML metadata file and its corresponding occupancy grid image.

## 2. Available Maps

- Map resolution.
- Map origin.
- Occupancy threshold.
- Free-space threshold.
