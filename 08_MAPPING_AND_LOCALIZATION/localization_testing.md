# Localization Testing

## 1. Testing Objectives

Evaluate the wheelchair's ability to estimate its position and orientation accurately within a saved map.

## 2. Test Procedures

| Test | Verification |
|---|---|
| Initial Pose | Check alignment between the wheelchair and map. |
| Stationary Localization | Check whether the estimated pose remains stable. |
| Straight Movement | Observe position tracking. |
| Rotation | Observe orientation tracking. |
| Full Route | Check for localization drift. |
| Obstacle Detection | Verify LiDAR scan alignment with the map. |
