# Project Introduction

## Project Name
Powered Wheelchair Autonomous Navigation System

## Overview
This project involves developing an autonomous powered
wheelchair using ROS 2 Humble.

## Main Computer
LattePanda 3 Delta

## Development Computer
Dell XPS 13

## Main Technologies
- ROS 2 Humble
- Nav2
- SLAM Toolbox
- AMCL
- Foxglove Studio

## Project Goals
1. Autonomous indoor navigation.
2. Environment mapping.
3. Obstacle detection and avoidance.
4. Predefined destination navigation.
5. Safe wheelchair operation.
