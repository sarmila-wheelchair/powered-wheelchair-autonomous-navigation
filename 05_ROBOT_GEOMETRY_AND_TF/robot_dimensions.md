# Robot Physical Dimensions

## 1. Overview

This document records the physical dimensions of the powered wheelchair platform.

These measurements are important for configuring the robot footprint, localization, obstacle avoidance, and autonomous navigation.

## 2. Known Physical Measurements

The following measurements have been recorded during the project.

| Parameter | Measurement | Description |
|---|---:|---|
| Front-to-back wheelbase | 90 cm | Distance between the front and rear wheel positions. |
| Left-to-right wheel distance | 68 cm | Physical distance between the left and right wheels. |
| Base link height above floor | 17 cm | Height of the `base_link` reference point above the floor. |
| Front extension from `base_link` | 45 cm | Distance from the reference point to the front edge. |
| Rear extension from `base_link` | 45 cm | Distance from the reference point to the rear edge. |

**Important:** These are recorded project measurements. Confirm the measurement reference points before using them for mechanical drawings or final navigation configuration.
