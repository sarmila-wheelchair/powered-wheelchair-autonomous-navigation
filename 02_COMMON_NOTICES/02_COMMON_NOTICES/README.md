## Important Reminder

This project involves a powered mobility device.

All hardware modifications, motor-control changes and autonomous navigation tests must be performed with appropriate safety precautions.

Software-based obstacle avoidance must not be treated as a replacement for a physical emergency stop or independent safety measures.
