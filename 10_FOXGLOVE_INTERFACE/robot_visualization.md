# Robot Visualization

## 1. Overview

The Foxglove 3D Scene panel is used to visualize the wheelchair model, coordinate frames, and spatial information from the ROS 2 system.

## 2. Coordinate Frame Visualization

The TF display is used to monitor the robot's coordinate frame relationships, including:

- `map`
- `odom`
- `base_footprint`
- `base_link`
- `velodyne`
- `camera0_link`
