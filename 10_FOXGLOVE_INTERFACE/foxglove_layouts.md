# Foxglove Dashboard Layouts

## 1. Overview

Foxglove Studio uses dashboard layouts to organize robot monitoring and visualization panels.

## 2. Dashboard Panels

Document the panels used in the wheelchair interface:

| Panel | Purpose |
|---|---|
| 3D Scene | Visualize the wheelchair, TF frames, and sensor point clouds. |
| Map | Display the saved environment map. |
| Navigation | Monitor navigation goals and paths. |
| Odometry | Monitor wheelchair position and movement. |
| Custom Destination Panel | Select predefined destinations and cancel navigation. |
