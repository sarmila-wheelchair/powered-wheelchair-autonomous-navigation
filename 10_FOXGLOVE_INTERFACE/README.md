# Foxglove Interface

## Overview

This section documents the Foxglove Studio interface used to monitor and interact with the powered wheelchair's ROS 2 navigation system.

Foxglove provides visualization of robot data, sensor information, maps, transforms, and navigation status.

## Interface Setup

- **Foxglove Studio:** Runs on the XPS 13.
- **Foxglove Bridge:** Runs on the LattePanda 3 Delta.
- **Bridge Port:** `8765`

## Interface Features

- Robot position and TF visualization.
- LiDAR and RealSense point cloud visualization.
- Map and costmap visualization.
- Odometry and velocity monitoring.
- Predefined destination navigation.
- Navigation cancellation.
