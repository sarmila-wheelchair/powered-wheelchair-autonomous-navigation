# Destination Panel

## 1. Overview

A custom Foxglove panel provides a way to send the wheelchair to predefined destinations and cancel an active navigation task.

The panel works with the custom ROS 2 node:

`place_nav_node.py`

## 2. Available Functions

The panel provides:

- Six predefined destination buttons.
- A navigation command for each destination.
- A cancel navigation button.
