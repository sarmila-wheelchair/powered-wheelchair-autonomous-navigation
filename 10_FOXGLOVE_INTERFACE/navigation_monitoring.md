# Navigation Monitoring

## 1. Overview

Foxglove Studio is used to monitor the wheelchair during autonomous navigation.

## 2. Navigation Topics

| Topic | Purpose |
|---|---|
| `/map` | Displays the saved occupancy map |
| `/odom` | Displays wheelchair odometry |
| `/cmd_vel` | Shows commanded velocity |
| `/plan` | Displays the planned path |
| `/local_costmap/costmap` | Displays the local costmap |
| `/global_costmap/costmap` | Displays the global costmap |
| `/tf` | Displays coordinate transforms |

## 4. Monitoring Checks

During navigation, monitor:

- Wheelchair position and orientation.
- Planned path and movement progress.
- Local and global costmaps.
- Sensor obstacle data.
- Velocity commands.
- TF frame alignment.
